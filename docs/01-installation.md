# Installation from scratch

## Prérequis (Ubuntu 22.04)

- Node.js >= 20
- npm >= 10
- Git >= 2.30 (configuré)
- Docker >= 24 + Docker Compose plugin

## Étapes

    git clone <URL_REPO> 01-gestion-devis
    cd 01-gestion-devis
    npm install
    docker compose up -d
    npm run dev:backend
    npm run dev:frontend
